# Source history

FxSound Peak Meter is an unofficial derivative of
[FxSound](https://github.com/fxsound2/fxsound-app). Original copyright notices and
the AGPL license are retained. See [NOTICE.md](NOTICE.md) and
[MODIFICATIONS.md](MODIFICATIONS.md).

This standalone repository starts from the application source snapshot
[`ad571fe`](https://github.com/Dronchiklolka/fxsound-peak-meter-history/commit/ad571feff95d8991f81270f6fac5ac8ad36d7709),
imported on 2026-10-22. The complete earlier Git history, original release and build
records remain in [fxsound-peak-meter-history](https://github.com/Dronchiklolka/fxsound-peak-meter-history).
Legacy compiled binaries and debug symbols from that history are not imported.

The 0.1.0 executable was built from
[`bf33b6f`](https://github.com/Dronchiklolka/fxsound-peak-meter-history/commit/bf33b6fe3e5fc666e2f19ee85db18c7de1ef4776)
by [this Windows build](https://github.com/Dronchiklolka/fxsound-peak-meter-history/actions/runs/39698338021).
Its corresponding source archive, including the exact JUCE 6.1.6 modules, is
provided with the release. The standalone import does not change the application
source or executable. The ZIP's SOURCE.txt identifies the archived build source.

Original FxSound base:
[`d8e7a23`](https://github.com/fxsound2/fxsound-app/commit/d8e7a23d37ed5939c2a3090a1c1756c7f2500b17).
The repository's independent GitHub status does not change the code's license or
its attribution to the original authors.
