# FxSound Peak Meter

[English](README.md) · [Описание выпуска](https://github.com/Dronchiklolka/fxsound-peak-meter/releases/tag/peak-meter-v0.1.0)

Неофициальный форк [FxSound](https://github.com/fxsound2/fxsound-app) с индикаторами
пиков до обработки, после эквалайзера и на выходе. Они показывают текущий уровень,
максимум и историю превышений. Алгоритмы обработки звука и драйвер не менялись.

**[Скачать для Windows x64](https://github.com/Dronchiklolka/fxsound-peak-meter/releases/download/peak-meter-v0.1.0/fxsound-peak-meter-0.1.0-windows-x64.zip)** — версия 0.1.0, предварительный выпуск.

## Установка

1. Если FxSound ещё не установлен, установите его с [официального сайта](https://www.fxsound.com/download).
   Он установит необходимый виртуальный аудиодрайвер.
2. Завершите запущенный FxSound через его значок в системном трее → «Выход».
3. Распакуйте **весь архив** в постоянную папку и запустите **FxSound.exe**.
4. Откройте полный вид окна: под спектром появятся **Вход / После EQ / Выход**.
   Если окно скрыто, откройте его через значок в трее.

Средства разработки для запуска не нужны. Одновременно работает один экземпляр
FxSound. Если открылся обычный FxSound без индикаторов, завершите его через трей
и снова запустите EXE из распакованной папки.

Архив не устанавливает драйвер и не заменяет системный автозапуск официальной
версии. Сборка использует настройки и пресеты FxSound, уже сохранённые на вашем
компьютере. В поставке — стандартные пресеты. У этой сборки нет цифровой подписи.

## Индикаторы

- **Вход / После EQ / Выход** — текущий пик и сохранённый максимум в dBFS.
- **OVER / Сброс** краснеет, когда сэмплы превышают цифровую границу или содержат
  некорректные значения. Нажатие очищает историю. Значения точно на границе
  учитываются отдельно и сами по себе не доказывают клиппинг.
- `-inf` означает тишину, `--` — отсутствие измерения в этой точке.

После EQ сигнал измеряется до эффектов и лимитера: перегруз там может не дойти
до выхода. Один сэмпл может быть учтён в нескольких точках.

Измеряется **sample peak**. Межсэмпловые пики, перегруз аналогового усилителя
и искажения, уже записанные в треке, этот индикатор не определяет.
